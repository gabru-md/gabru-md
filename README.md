# Manish Devgan

I still keep this GitHub profile public for older projects, open-source work, and things I want to share publicly.

These days, most of my active development happens on my own home lab server. I run a small self-hosted setup on a Raspberry Pi, with my private Git server, app deployments,
automation, notes, budgeting, and experiments all living locally.
